# Tcg-Pocket-Dex


## 각 계층에 맞는 VO 로 사용

할 작업들이 아주 많구만.

## All cards 화면에서 place holder 의 크기 맞추기

## Tier decks 화면에서 실제 api 를 연결해야 해.

이제 아래 작업을 해보자. 
사실은 아래 작업은 서버에서 해주어서 클라이언트 코드는 깔끔하게 남기고 싶기는 한데. 
그건 나중에 서버를 도입할 때 책임지기로 하자.

그러면 현재 클라어언트(안드로이드 프로젝트)에서 여러번 api 를 호출하고 결과 받아서 다시 호출하는 부분이 나중에 변경될 부분이네.

내가 나중에 서버를 도입한다고 했을 때 클린 아키텍처의 그림에서 최대한 안 쪽의 코드는 변경되지 말아야 하고, 
최대한 바깥 쪽의 코드만 변경되어야 하겟네.

그리고 인터페이스는 그대로 두고, 구현체만 바뀌어야 하겠네.
그러한 동작들을 잘 생각해서 작업을 하면 되겟다.

'인기 덱 목록' 화면을 만드는 것은 여러 API를 순차적으로 호출하고, 그 결과를 가공해야 하는 복합적인 작업입니다.

이 과정은 크게 **데이터 수집 및 가공 단계**와 **UI 표시 단계**로 나뉩니다.

---

### ### 1부: 데이터 수집 및 가공 단계 (Data Layer)

이 단계의 목표는 Limitless TCG API를 사용하여 화면에 표시할 통계 데이터(덱 이름, 점유율, 승률 등)를 만드는 것입니다.

#### #### 📡 1단계: 분석할 토너먼트 ID 목록 가져오기

먼저, 어떤 토너먼트들의 데이터를 분석할지 정해야 합니다. 최근에 열린 '포켓몬 TCG 포켓' 토너먼트 목록을 가져옵니다.

* **API 호출:** `https://play.limitlesstcg.com/api/tournaments?game=POCKET`
* **결과:** 지난 대화에서 직접 확인하신 것처럼, 여러 토너먼트 정보가 담긴 JSON 배열을 받게 됩니다.
* **처리:** 이 중에서 참가자 수가 너무 적지 않은(예: `players > 32`) 의미 있는 대회들의 `id`만 추출하여 목록으로 만듭니다.

#### #### 🔢 2단계: 모든 토너먼트에서 상위권 덱 리스트 수집하기

1단계에서 얻은 토너먼트 ID 목록을 사용해, 각 토너먼트의 상세 결과를 가져옵니다.

* **API 호출:** 1단계에서 얻은 각 `id`에 대해 `https://play.limitlesstcg.com/api/tournaments/{id}/standings` 를 반복적으로 호출합니다.
* **결과:** 모든 토너먼트의 참가자 순위 및 덱 리스트 데이터가 담긴 거대한 JSON 배열을 얻게 됩니다.
* **처리:** 이 중에서 유의미한 데이터(예: 8강 이내 `placing <= 8`)만 필터링하여 다음 단계로 넘깁니다.

#### #### 📊 3단계: 덱 유형(Archetype)별로 데이터 그룹화 및 통계 계산

2단계에서 수집한 방대한 데이터를 이제 '덱 유형'별로 묶어서 통계를 내야 합니다. API 응답의 `deck` 객체가 이 역할을 합니다.

* **처리:**
    1.  `Map<String, DeckStats>` 형태의 비어있는 맵을 만듭니다. 여기서 Key는 `deck.id`(예: `"charizard-ex-sylveon-ex-a3b"`)가 됩니다.
    2.  2단계에서 얻은 모든 덱 리스트를 순회하면서, 각 덱의 `deck.id`를 Key로 하여 맵에서 `DeckStats` 객체를 찾거나 새로 만듭니다.
    3.  해당 `DeckStats` 객체에 아래 정보를 누적하여 더합니다.
        * **출전 횟수 (count):** 1씩 증가시킵니다. (나중에 점유율 계산에 사용)
        * **승리 수 (wins):** `record.wins` 값을 더합니다.
        * **패배 수 (losses):** `record.losses` 값을 더합니다.
* **결과:** 각 덱 유형별로 총 출전 횟수, 총 승리, 총 패배가 집계된 데이터가 만들어집니다.

#### #### 🏆 4단계: 최종 통계 계산 및 정렬

3단계에서 집계한 데이터를 바탕으로 최종적으로 화면에 보여줄 승률(Win%)과 점유율(Share%)을 계산합니다.

* **처리:**
    1.  3단계에서 만든 맵의 각 항목에 대해 아래 계산을 수행합니다.
        * **승률:** `total_wins / (total_wins + total_losses)`
        * **점유율:** `count / (분석한 전체 덱의 수)`
    2.  계산된 결과를 점유율(Share%)이나 승률(Win%)이 높은 순서대로 정렬합니다.
* **결과:** 화면에 표시할 최종적인 '인기 덱' 순위 목록 데이터가 완성됩니다. (예: `List<CalculatedDeck>`)

### ### 2부: UI 표시 단계 (Presentation Layer)

이제 완성된 데이터를 가지고 실제 UI를 그립니다.

#### #### 🖼️ 5단계: 덱 대표 아이콘 이미지 URL 가져오기

4단계에서 만든 데이터에는 `deck.icons` (예: `["charizard", "sylveon"]`) 정보가 있습니다. 이 포켓몬 이름들을 실제 이미지 주소로 바꿔야 합니다. 여기서 **TCGdex API**가 사용됩니다.

* **처리:**
    1.  **미리 TCGdex로부터 모든 카드 정보를 받아 로컬 DB나 메모리에 저장해 둡니다.** (이전에 알아낸 `.../series/tcgp` -> `.../sets/{id}` 호출 방식 사용)
    2.  `icons` 배열의 이름(예: "charizard")을 사용하여, 미리 받아둔 카드 목록에서 해당하는 포켓몬 카드(가급적 'ex'나 'V'가 붙은 카드)를 검색합니다.
    3.  검색된 카드의 `image` URL을 가져와 UI에 표시할 준비를 합니다.

#### #### 📱 6단계: Compose UI에 데이터 표시하기

이제 모든 데이터가 준비되었습니다. `LazyColumn`을 사용하여 순위 목록을 그립니다.

* **처리:**
    1.  `LazyColumn`이 4단계에서 만든 `List<CalculatedDeck>`를 순회합니다.
    2.  각 아이템에서는 `Row`를 사용하여 순위(`1`, `2`, ...), 5단계에서 찾은 **덱 대표 아이콘 이미지들(AsyncImage 사용)**, 덱 이름, 승률, 점유율 텍스트를 화면에 표시합니다.

이 모든 과정을 거치면 사용자께서 원하시는 '인기 덱 목록' 화면을 성공적으로 만들 수 있습니다.
